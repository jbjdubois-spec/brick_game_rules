# Tetris by Retro Nono

Page de choix des jeux du Tetris imprimé en 3D pour l'École des Bois (Martillac) :

- 5 jeux (grand puzzle, copie-moi, pioche mystère, lignes à deux, images), 3 niveaux chacun ;
- 38 cartes images à reproduire avec les pièces, de difficulté 1 à 5 ;
- bandeau animé et musique chiptune (à lancer depuis la page).

Site en ligne : https://jbjdubois-spec.github.io/brick_game_rules/
